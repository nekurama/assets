# Nekurama shared assets

Public reference library for approved Nekurama and Babai visual assets. Files in this repository are publicly readable.

## Contents

### Babai

- Mascot illustrations: package delivery, billing, owner, onboarding, cooking, chat, storefront, welcome counter, order taking, and business growth.
- Brand marks: wordmark illustration and monochrome face icon.

### Nekurama

- Fox mascot illustrations in classic, medallion, bag-emblem, circuit, and tech-orbit variants.
- Logo marks: wordmark and line-art mark.

## Referencing an asset

For a stable reference, pin the URL to a release tag or commit rather than `main`. Example after the first release:

```markdown
![Babai mascot](https://raw.githubusercontent.com/nekurama/assets/v1.0.0/babai/mascot/babai-package-delivery.jpeg)
```

The source images were supplied as JPEGs and are preserved without image edits. Descriptive filenames are used for easier discovery. Animated companion or pet GIFs can be added under `pets/` when their files are available.
