## Referencing an asset

For a stable reference, use the `v1.0.0` tag or a commit SHA instead of `main`. Example:

```markdown
![Babai mascot](https://raw.githubusercontent.com/nekurama/assets/v1.0.0/babai/mascot/babai-package-delivery.jpeg)
```

The source images were supplied as JPEGs and are preserved without image edits. Descriptive filenames are used for easier discovery. Pet-related GIFs can be added under `pets/` when their files are available.
